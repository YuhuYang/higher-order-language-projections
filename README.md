# Higher-order structures in language

This repository contains the analysis code for *Can higher-order structures in language be recovered from pairwise projections?*

The workflow constructs one lexical hypergraph per treebank from CoNLL-U dependency data. Each non-punctuation head and its direct non-punctuation dependents form a hyperedge; singleton hyperedges are discarded. The scripts compare these hypergraphs with their pairwise projections, quantify clique–hyperedge non-equivalence and recoverability, run projection-preserving null models, and evaluate hyperedge-boundary prediction.

## Contents

```text
scripts/
  run_analysis.py   full analysis pipeline
  make_figures.py   generate manuscript Figures 2–5 from result tables
requirements.txt
```

Figure 1 is not generated by code. Data, generated results, and manuscript source files are intentionally not included.

## Data

Download the SUD/PUD CoNLL-U files used in the study and place the `.conllu` files in one directory. The analysis treats each file as one treebank and derives the language identifier from the portion of its filename before the first underscore.

## Environment

Python 3.11 or later is recommended.

```bash
python -m venv .venv
python -m pip install -r requirements.txt
```

## Run the analysis

```bash
python scripts/run_analysis.py \
  --data-dir path/to/conllu \
  --out-root results \
  --run-name main_analysis
```

The default settings reproduce the reported analysis, including 100 projection-preserving null samples per treebank and the fixed random seed `20260505`. Each run creates a separate directory containing CSV tables, a short summary, a progress log, and a machine-readable manifest.

Use `python scripts/run_analysis.py --help` to see the sampling limits and other options.

## Generate Figures 2–5

```bash
python scripts/make_figures.py \
  --tables-dir results/main_analysis/tables \
  --output-dir figures
```

Each figure is saved as both PNG and PDF. `make_figures.py` expects the tables produced by `run_analysis.py`.
